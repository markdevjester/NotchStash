# NotchStash

[English](README.md) · **Русский**

Бесплатный менеджер буфера обмена для Mac, который живёт в чёлке. Сделано [markdev](https://github.com/markdevjester). Запоминает всё скопированное (текст, картинки, файлы) и хранит историю на диске между перезапусками.

## Установка

1. Скачайте `NotchStash-1.0.1.zip` со страницы [Releases](https://github.com/markdevjester/NotchStash/releases/latest), распакуйте и перетащите `NotchStash.app` в «Программы».
2. Первый запуск: приложение пока не подписано у Apple, поэтому macOS скажет, что не может проверить разработчика.
   Откройте «Системные настройки → Конфиденциальность и безопасность», пролистайте вниз и нажмите «Всё равно открыть».
3. Иконка появится в строке меню, история — по **⇧⌘V** или наведением на чёлку.

## Как пользоваться

- **⇧⌘V** — история выезжает из чёлки. Ещё можно навести мышь на чёлку.
- **↑ ↓** — выбрать, **↩** — вставить в текущую программу, **⌥↩** — только скопировать.
- **⌘1–9** — сразу вставить запись по номеру.
- **⌘L** — вставить с исправленной раскладкой («ghbdtn» → «привет», «руддщ» → «hello»).
- **⌘T** — вставить текст с выбранной картинки.
- **⌘P** — закрепить (закреплённые всегда сверху и не удаляются при чистке).
- **⌘⌫** — удалить запись, **esc** — закрыть.
- Язык интерфейса — как в системе (русский или английский), меняется в меню: «Язык».
- **⇥** — переключить «Историю» и «Полку».
- После каждого копирования чёлка на секунду показывает «Скопировано».
- Иконка в строке меню: последние 10 записей, пауза, настройки, автозапуск.

## Текст со скриншотов

Каждая скопированная картинка прочитывается встроенным в macOS Apple Vision (русский, английский, украинский) — прямо на Mac, без интернета.
- Текст виден под картинкой: можно вставить (**⌘T**), скопировать или выделить кусок.
- Ссылки, почта и телефоны с картинки становятся кнопками.
- Поиск ищет и по тексту на картинках: «трек», «счёт», «пароль» найдут нужный скриншот.
- Старые картинки в истории дочитываются в фоне после запуска. Выключается в меню: «Распознавать текст на картинках».

## Полка

Тащите файл, картинку, ссылку или текст к чёлке — она раскрывается и принимает вещь на полку.
Потом вещь можно вытащить из чёлки в любую программу, вставить (↩), открыть двойным кликом,
показать в Finder или отправить по AirDrop (по одной или всё сразу).
Файлы на полке — это ссылки на оригиналы; временные файлы (превью скриншота) и картинки из браузера копируются в папку полки.
Записи из истории тоже можно вытаскивать мышью прямо из списка.

## Умные карточки

NotchStash сам понимает, что вы скопировали:

- **Не та раскладка** — подсказка с исправленным текстом (проверка по словарям macOS, без интернета).
- **Цвет** (`#FF5A5F`, `rgb()`, `hsl()`) — образец цвета и перевод в HEX / RGB / HSL одним кликом.
- **Пример** (`1499 * 12 - 15%`) — сразу ответ, проценты как на калькуляторе.
- **Ссылка** — домен, «Открыть» и «Без слежки» (убирает utm, fbclid, si и другие метки).
- **JSON** — красивое форматирование и сжатие в одну строку.
- **Код и команды терминала** — подсветка синтаксиса.
- **Почта** — «Написать письмо».

Для обычного текста есть кнопки: раскладка, транслит, ВЕРХНИЙ, нижний, как в предложении, в одну строку.

Пароли из менеджеров паролей (помеченные как скрытые) не сохраняются.

## Автовставка

Чтобы ↩ сразу вставлял текст, macOS должна разрешить приложению нажимать ⌘V:
Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → включить «NotchStash».
Без этого запись просто копируется в буфер, и вставить её можно своим ⌘V.
После каждой пересборки разрешение нужно выдать заново (меняется подпись).

## Где лежит история

`~/Library/Application Support/NotchStash/` — `history.json`, папка `images/` и папка `shelf/` (полка).

## Сборка

Нужен Swift (Xcode или Command Line Tools). Если лицензия Xcode не принята, скрипт сам соберёт через Command Line Tools.

```bash
zsh build.sh            # собрать build/NotchStash.app (Apple Silicon + Intel)
zsh build.sh --install  # собрать, положить в /Applications и запустить
zsh build.sh --release  # собрать архив для GitHub
```

Проверка без экрана: `NOTCHSTASH_DATA_DIR=<папка> NOTCHSTASH_SNAPSHOT=out.png build/NotchStash.app/Contents/MacOS/NotchStash`
рисует раскрытую панель в PNG (`NOTCHSTASH_STATE=peek` — вспышку, `NOTCHSTASH_SELECT=n` — какую запись выбрать, `NOTCHSTASH_TAB=shelf` — полка, `NOTCHSTASH_DROP=1` — момент перетаскивания).

Тесты (раскладка, калькулятор, цвета, ссылки, JSON, код, полка, текст с картинок):

```bash
swiftc -swift-version 5 Sources/L10n.swift Sources/Smart.swift Sources/Store.swift Sources/Shelf.swift Sources/OCR.swift Tests/main.swift -o /tmp/notchstash-test && /tmp/notchstash-test
```
